# 邮件 HTML 模板

本目录只存放邮件正文 HTML 模板，不包含发送逻辑。

| 文件 | 用途 |
| --- | --- |
| `apple.html` | 苹果官网式、留白较多、适合产品通知和高层摘要 |
| `minimal.html` | 极简文本风、适合普通通知和简短结果 |
| `business-report.html` | 企业报告风、适合周报、质量报告和正式汇报 |
| `alert.html` | 告警通知风、适合异常、风险、监控事件 |
| `dark-tech.html` | 深色科技风、适合系统状态、Agent 和技术报告 |

所有模板均为独立 HTML，无 JavaScript、无外部字体、无外链 CSS，并包含：

- H1 / H2 / H3 / H4 标题
- 正文与补充说明
- 无序 / 有序列表
- 重点提示块
- 表格
- 按钮
- 代码 / 日志块
- 页脚

直接复制模板并替换示例内容即可使用。

## 夜间模式

浅色模板声明 `light dark`，通过 `prefers-color-scheme: dark` 同时切换背景、正文、辅助文字和链接颜色；Outlook 使用 `[data-ogsc]` 兼容规则。深色科技模板保留深色配色。

不要给文字添加固定的 `-webkit-text-fill-color`，否则客户端自动变换背景时可能出现深色文字落在黑色背景上的问题。内联颜色作为不支持媒体查询的客户端回退，夜间样式通过类选择器覆盖。

浏览器预览能验证主题、对比度及窄屏布局，但不等于所有邮件客户端的真实渲染。已发送邮件和已入队 HTML 快照不会随模板更新改变。
